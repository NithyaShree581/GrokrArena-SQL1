# GrokrArena SQL Assignment

This repository contains my SQL solutions for the GrokrArena SQL Assignment (Questions 1–10).

The solutions cover SQL queries, data manipulation, joins, subqueries, aggregate functions, and other important SQL concepts.

## Questions Covered

| Question | Problem Description | SQL Concepts |
|---|---|---|
| 1 | SQL Assignment – Question 1 | SQL Queries |
| 2 | Find the Nth Highest Salary | Functions, DISTINCT, ORDER BY, LIMIT, OFFSET |
| 3 | Find the Person with the Most Friends | UNION ALL, GROUP BY, COUNT |
| 4 | Exchange Seats Between Consecutive Students | CASE WHEN, Subqueries |
| 5 | Customers Who Bought All Products | GROUP BY, HAVING, COUNT DISTINCT |
| 6 | Number of Orders Made by Each Buyer in 2019 | LEFT JOIN, COUNT, YEAR |
| 7 | First Login Date Within 90 Days | MIN, GROUP BY, Subqueries |
| 8 | Product Prices on a Specific Date | Subqueries, COALESCE, ORDER BY |
| 9 | Transactions and Chargebacks | CTE, UNION ALL, JOIN, Aggregate Functions |
| 10 | Calculate Football Team Points | CASE WHEN, LEFT JOIN, UNION ALL, GROUP BY |
